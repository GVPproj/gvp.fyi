# Generated ambient test kit

These 16 original, synthetic sine recordings are public-domain fixtures,
not the instrument's final sound design. No third-party recordings, assets,
libraries or training data were used. To the extent copyright applies, the
fixtures and their generator are dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Reproduce from the repository root with Python 3 (standard library only):

```sh
python3 scripts/generate-ambient-samples.py
python3 scripts/generate-ambient-samples.py --check
```

The generator writes deterministic, header-only-metadata PCM WAV files:
24,000 Hz, mono, signed 16-bit little-endian, exactly 48,000 frames (2 seconds),
96,044 bytes each. The kit totals 1,536,704 bytes. Each note uses equal temperament
with A4 = 440 Hz, zero starting phase, an 80 ms linear attack, unity sustain,
and a 600 ms linear release. The engine adds 0.8/32 per-voice headroom and
limits polyphony to 32, including future scheduled starts.

The notes are C3 D3 E3 G3 A3 C4 D4 E4 G4 A4 C5 D5 E5 G5 A5 C6.
Lowercase filenames match stable sound IDs in `src/lib/lib-ambient-pad/ambient-kit.ts`.
If changing the mapping/envelope, update the generator and engine together;
the browser audio tests compare all generated voices with their sine counterparts.

`--check` compares every generated byte without overwriting fixtures. Generation
uses Python's platform math library; byte verification was performed with Python 3
on Linux (extremely rare rounding differences on another math library are possible).
These short fixtures do not establish budgets for future long ambient recordings.

## Audio-engine verification

```sh
node --test tests/ambient-audio.test.js
```

Tests render real Chromium `OfflineAudioContext` output and exercise native
`AudioContext` activation/suspension. A lifecycle boundary adapter controls
otherwise nondeterministic interruption and network/decode races. Use a cached
Playwright Chromium or set `PLAYWRIGHT_CHROMIUM_EXECUTABLE`; without either,
the browser suite skips explicitly. No new runtime/test dependencies are needed.
Firefox, Safari and real mobile-device listening still need manual verification.
