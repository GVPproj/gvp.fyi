My OS of choice when OS is a choice.  Sturdy and easy to set up.  I tried a few distros.  If you don't feel like 'maintaining your distro', which obviously can be a fun thing if you've got time for that (see [Too Many Hobbies: 2026 Edition](/blog/too-many-hobbies-2026-edition/)), then this is the one.  

The LMDE version was the only one I could get going on my ancient Macbook Pro and it works perfectly there.

Otherwise I use it on a lenovo machine daily and the experience/speed is A+.
