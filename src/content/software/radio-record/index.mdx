A self-hosted tool for capturing weekly CHIR FM broadcasts and preparing recordings for sharing. A scheduled job records the stream, and a password-protected Go web app provides playback and downloads.

The player includes a zoomable waveform, playback speed controls and keyboard shortcuts for setting trim points. Select a section, preview it, and optionally add an intro or outro station ID before downloading a merged FLAC.

Built with Go’s HTML templates and FFmpeg, running on a Debian laptop behind a Cloudflare Tunnel.
