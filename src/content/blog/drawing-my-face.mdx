This is a drawing of my face, done by my partner <a href="https://sophiaburke.ca/" target="_blank" rel="noopener noreferrer">Sophia</a>. For the sake of the animation idea, we kept it as a single stroke so the drawing can be converted to an SVG path and revealed with a CSS animation.

Once we have the SVG, setting `pathLength="1"` lets us treat the whole path as one unit long, rather than having to measure the length (we could use JavaScript to measure the path with `path.getTotalLength()`, but this way we are JS-free).

`stroke-dasharray: 1` makes a dash followed by a blank space, each as long as the whole drawing. The dash is the visible part of the line. The blank space is where nothing gets drawn. They follow the same path, rather than being two separate drawings.

`stroke-dashoffset: 1` shifts the pattern so the blank space covers the whole path, hiding the stroke.

As the CSS animation changes the offset from 1 to 0 over four seconds, the dash gradually replaces the blank space, revealing the drawing from start to finish. We use `ease-out` to slow it down towards the end. That's it!

A nice challenge would be to build something similar out of multiple paths, managing the animation timings to get a similar 'see how it's drawn' effect.

Here's the `Face.astro` component, with the long SVG path data omitted for readability.

```astro
---
interface Props {
  scale?: number
}

const { scale = 1 } = Astro.props
const width = 300 * scale
const height = 340 * scale
---

<svg
  class="face"
  viewBox="0 0 350 500"
  role="img"
  width={width}
  height={height}
>
  <title>A one-line portrait of my face</title>
  <path
    pathLength="1"
    d="…"
    stroke="currentColor"
    stroke-width="8"
    stroke-linecap="round"
    fill-opacity="0"
  />
</svg>

<style>
  .face {
    display: block;
    max-width: 100%;
    max-height: calc(100svh - 3rem);
  }

  .face path {
    stroke-dasharray: 1;
    stroke-dashoffset: 1;
    animation: draw-face 4s ease-out forwards;
  }

  @keyframes draw-face {
    to {
      stroke-dashoffset: 0;
    }
  }

  @media (prefers-reduced-motion: reduce) {
    .face path {
      animation: none;
      stroke-dashoffset: 0;
    }
  }
</style>
```
